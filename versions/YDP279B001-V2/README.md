## 产品简介

OSPTEK **2.79 寸 142×428 TFT** 是一款 **4-wire SPI** 接口彩色显示模组，驱动 IC 为 **NV3007A**。细长比例适合状态条、侧边信息面板和紧凑型 HMI。

规格标识（仓库名）：`tft-2.79-142x428-spi-nv3007`

当前模组版本：**YDP279B001-V2**。电气与外形细节以 [`docs/YDP279B001-V2.pdf`](./docs/YDP279B001-V2.pdf) 为准。

## 规格参数

| 项目 | 规格 |
| ---- | ---- |
| 尺寸 | 2.79 英寸 |
| 类型 | TFT（透射式） |
| 分辨率 | 142×428 |
| 接口 | 4-wire SPI |
| 驱动 IC | NV3007A |
| FPC | 10 Pin |
| 触摸 | 无 |
| 模组尺寸 | 24.38 × 69.43 × 2.15 mm |
| 有效显示区 | 21.28 × 64.14 mm |
| 工作温度 | -20～85 ℃ |
